The IPMI Java Client talks to the Baseboard Management Controller (BMC) of a server over IPMI 2.0 over LAN (RMCP+).

  • {@link org.metricshub.ipmi.client} is the client API: start with {@link org.metricshub.ipmi.client.IpmiClient}.
  • The {@code org.metricshub.ipmi.core} packages are the protocol layer that {@code IpmiClient} uses: {@link org.metricshub.ipmi.core.api.sync.IpmiConnector}, the command coders and the SDR, FRU and SEL decoders.
  • {@link org.metricshub.ipmi.cli.IpmiCli} is {@code ipmicli}, the command-line client.

User guide: https://metricshub.org/ipmi-java/
